Arti is a small project-owned neural language model for an ESP32 WROVER-E.
Arti runs neural inference locally on the ESP32.
The model weights are stored in the ESP-Arti GitHub repository and downloaded by the firmware at startup.
GitHub is storage and distribution for the model. GitHub does not perform inference for Arti.
The flashed ESP32 firmware is the inference runtime.
The model is loaded into PSRAM because the WROVER-E has external PSRAM.
A reset or power loss removes the downloaded model from RAM, so the firmware downloads it again.
The current model is trained from this file, training/corpus.txt.
Training changes numerical model weights.
Inference uses the trained weights to predict the next byte.
Arti uses a byte-level vocabulary with 256 possible byte values.
A byte-level model can represent normal ASCII text without a separate word tokenizer.
Arti is not a cloud AI service.
Arti does not download a pretrained third-party language model.
Arti does not compile downloaded model data as C++ code.
The binary model file contains numerical weights and configuration data.
The firmware interprets those weights using the neural-network architecture it was built for.
The ESP32 and the model file must use the same architecture and binary format.
If the model format changes, the firmware loader must be updated to match it.
